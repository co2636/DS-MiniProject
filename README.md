# ESS 배터리 수명 예측

배터리의 초기 100사이클 충·방전 신호를 이용해 최종 수명(`cycle_life`)을 예측합니다. Batch별 EDA에서 유의미한 신호를 찾아 모델 설계에 반영하고, 새로운 Batch에서도 예측이 유지되는지 평가합니다. 향후 ESS 점검 우선순위와 교체 계획에 활용할 가능성을 검토하는 것이 목적입니다.

## 프로젝트 개요

- 데이터셋: MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터: **Batch 1 (2017-05-12), 확정 라벨 36셀**
- 평가 데이터: **Batch 2 (2018-02-20), 확정 라벨 39셀**
- 태스크: **Regression — Cycle Life 예측**
- 입력: 초기 100사이클 이내에서 추출한 피처
- 주 평가 지표: MAPE(%), 보조 지표: MAE·RMSE(사이클)
- Batch 3: DAY1 EDA 비교에만 사용하며 DAY2 테스트는 제외
- 최종 모델: Elastic Net, Batch 2 MAPE **25.642%** — 과제 목표 9.1% 미달

## EDA

### Cycle Life 분포

| Batch | 확정 라벨 셀 수 | 평균 | 중앙값 | 최소~최대 | 단수명 <500 | 장수명 >1,000 |
|---|---:|---:|---:|---:|---:|---:|
| Batch1 | 36 | 788.4 | 772.5 | 534~1,074 | 0.0% | 13.9% |
| Batch2 | 39 | 565.7 | 472.0 | 392~1,186 | 71.8% | 7.7% |
| Batch3 | 44 | 1,059.7 | 1,005.5 | 541~1,935 | 0.0% | 52.3% |

수명 단위는 사이클이며 비율의 분모는 확정 수명 라벨이 있는 셀입니다. 전체 셀 B1/B2/B3 46/47/46개 중 라벨이 없는 10/8/2개는 지도학습과 수명 통계에서 제외했습니다. 수명을 평균이나 관측 길이로 대체하지 않았습니다.

**핵심 발견:** Batch 1에는 500 미만 수명이 없지만 Batch 2의 71.8%가 그 구간에 있습니다. Batch 3은 장수명 비율이 가장 높습니다. Batch 비교는 가장 좋은 Batch를 고르는 과정이 아니라, 새로운 데이터에서 달라지는 조건을 확인하는 과정입니다. 따라서 내부 검증과 Batch 2 외부 성능을 구분합니다.

### 열화 곡선 분석

사이클별 방전용량(QD)을 그려 장·단수명 셀의 용량 유지와 감소 시점을 비교했습니다. 단수명 셀은 더 이른 사이클에 용량 감소가 나타나며, 셀별 열화 속도는 전 구간에서 일정하지 않습니다. 중기 대비 말기 감소 속도 비율 중앙값은 B1/B2/B3에서 약 11.9/12.0/9.4배였습니다.

**핵심 발견:** 말기에 열화가 가속되는 양상이 있어 단일한 일정 감소율로 전체 수명을 설명하기 어렵습니다. 이동평균과 곡선 변화량으로 Knee 후보를 탐색했지만 잡음·끝단·탐색 방법에 민감하므로 실제 급락 시작점으로 확정하지 않았습니다. 전체 곡선의 Knee와 중·말기 기울기는 미래 정보여서 예측 입력에 넣지 않습니다.

1.2 Ah를 넘는 용량 돌출 기록은 주변 기록과 불연속성을 확인한 뒤 가공 단계에서 제외했습니다. 원본과 셀 전체를 삭제하지 않았으며, 제외 이력은 재처리 결과에 남깁니다.

### ΔQ(V) 곡선 분석

100사이클과 10사이클의 방전 곡선 차이 `ΔQ(V)=Q100(V)−Q10(V)`를 비교했습니다. 대표 단수명 셀에서 더 깊은 음의 변화가 관찰됐고, 곡선의 분산·최솟값 등을 피처로 요약했습니다.

**핵심 발견:** ΔQ 로그분산과 수명의 상관은 B1/B2/B3에서 **−0.827/−0.902/−0.702**로 음의 방향을 유지했습니다. ΔQ 단독 회귀를 기준 모델로 두고 다른 초기 신호를 더했을 때의 효과를 검증했습니다. 대표 곡선만으로 모든 셀이 완전히 구분된다고 해석하지 않습니다.

### 충전 속도(C-rate)와 수명의 관계

확정 라벨 기준으로 충전 프로토콜별 평균 수명을 비교했습니다.

| Batch | 최저 평균 수명 정책 | 평균 / 셀 수 | 최고 평균 수명 정책 | 평균 / 셀 수 |
|---|---|---:|---|---:|
| Batch1 | `5.4C(80%)-5.4C` | 546.5 / 2 | `4.4C(80%)-4.4C` | 1,074.0 / 1 |
| Batch2 | `3.6C(9%)-5C` | 394.5 / 2 | `5.6C(26%)-4.5C-newstructure` | 991.3 / 3 |
| Batch3 | `3.7C(31%)-5.9C-newstructure` | 660.0 / 3 | `4.8C(80%)-4.8C-newstructure` | 1,564.2 / 6 |

평균 수명의 단위는 사이클입니다. 정책별 표본 수가 작으므로 위 최고·최저 평균은 정책의 우열이나 인과효과를 입증하지 않습니다.

**핵심 발견:** 실측 전류 Iqw와 수명의 상관은 B1/B2/B3에서 **−0.845/−0.301/−0.650**이며 Batch 2에서는 관계가 약했습니다. C-rate 하나만으로 수명을 설명하기 어렵고, 셀 구조·전환 SOC·온도 등의 조건이 함께 작용할 수 있습니다. 전류·충전시간을 별도 후보 조합으로 비교하고 충전 정책 그룹을 분리해 검증했습니다.

### 상관관계와 다중공선성

초기 피처 사이에 절대 상관 0.90 이상인 쌍이 Batch별 30~36개였습니다. 초기 SOH 기울기의 수명 상관은 **+0.507/−0.442/+0.333**으로 Batch에 따라 부호가 달랐습니다.

**핵심 발견:** 중복 신호를 한꺼번에 넣으면 작은 표본에서 계수가 불안정해질 수 있습니다. 규제 회귀인 Ridge·Elastic Net을 우선 비교하고, 관계가 불안정한 변수는 기본 조합에서 제외하거나 추가 조합으로 검증했습니다. 상관계수는 예측 성능이나 원인 효과를 뜻하지 않습니다.

## Modeling

### 피처 엔지니어링 전략

EDA에서 관계가 유지되는 ΔQ 신호를 기준으로, 초기 용량 수준과 변화 양상을 보완했습니다.

| 최종 후보 피처 | 계산·의미 | 포함 이유 |
|---|---|---|
| `delta_q_log_variance` | ΔQ 분산의 로그 | 세 Batch에서 일관된 음의 수명 상관 |
| `delta_q_log_abs_min` | ΔQ 최솟값 절댓값의 로그 | 곡선의 큰 음의 변화 크기를 요약 |
| `qd_cycle2` | 2사이클 방전용량 | 초기 용량 수준 |
| `qd_max_minus_cycle2` | 2~100사이클 최대 QD−2사이클 QD | 초기 증가·안정화 양상 |
| `qd_slope_cycle2_100` | 2~100사이클 QD의 직선 기울기 | 초기 변화 방향과 속도 |

단독 ΔQ, 방전 확장, 추가 신호 확장, 전류 추가, 충전시간 추가의 5개 조합을 비교했습니다. 후보의 물리적 의미만으로 선정하지 않고 CV MAPE로 효과를 확인했습니다. 최종 전체 Batch 1 재학습에서 로그분산 계수는 0이 되어 실제 비영 계수는 4개입니다. 중복 신호의 추가 기여가 축소된 것이며 ΔQ 신호가 무의미하다는 뜻은 아닙니다.

셀 ID·충전 정책 문자열·전체 곡선 Knee·중말기 기울기·관측 길이·정답 수명은 예측 피처에 넣지 않았습니다. 충전 정책은 그룹 분리에 사용합니다. 논문 Discharge의 6개 선택 피처와 동일한 구현이 아니라 논문 아이디어를 참고한 방전 5개 조합입니다.

### 모델 선택 및 근거

- **후보 모델:** Ridge, Elastic Net, Bayesian Ridge, SVR, Kernel Ridge, Random Forest, Extra Trees, Gradient Boosting 및 Voting·Stacking·Bagging. 중앙값 Dummy도 기준선으로 비교했습니다.
- **최종 모델:** `ElasticNet(alpha=0.001, l1_ratio=0.5)`, `log10(cycle_life)`를 학습하고 사이클 단위로 역변환합니다.
- **선택 이유:** 정한 후보군에서 개발용 평균 CV MAPE가 **4.775%로 가장 낮았습니다.** 작은 표본·중복 피처에 적합한 규제 특성도 보조 근거입니다. 외부 배치와 운영 위험까지 검증된 최적 모델이라는 뜻은 아닙니다.

추가 비교의 각 모델 계열에서 가장 낮은 CV 결과는 다음과 같습니다. 피처·Target·설정이 함께 달라 알고리즘만의 통제 비교는 아닙니다.

| 모델 계열 | 최저 CV MAPE (%) | fold 표준편차 (%p) | 판단 |
|---|---:|---:|---|
| ElasticNet | 4.775 | 1.718 | 방전 5개·로그 Target. CV 최소로 최종 선택 |
| BayesianRidge | 4.928 | 1.875 | 계수 불확실성을 다루는 선형 비교군. CV가 더 높음 |
| Voting | 4.984 | 1.528 | Elastic Net + Ridge 50:50. CV 개선 없음 |
| Ridge | 4.994 | 1.939 | 방전 5개·로그 Target. 차이는 작지만 CV가 더 높음 |
| Stacking | 5.392 | 1.756 | 내부 그룹 OOF 기반 결합. CV 개선 없음 |
| Bagging | 5.418 | 1.275 | 정책 재표집 40개 모델 평균. CV 개선 없음 |
| ExtraTrees | 7.968 | 3.568 | 무작위 트리 평균. 비교한 설정에서 오차가 큼 |
| KernelRidge | 8.489 | 3.250 | 비선형 커널 회귀. ΔQ 단독이 계열 내 최선 |
| SVR | 8.626 | 2.770 | 비선형 회귀. ΔQ 단독·원 Target이 계열 내 최선 |
| GradientBoosting | 9.613 | 4.126 | 잔차를 순차 보완. 제한한 설정에서 CV가 더 높음 |
| RandomForest | 9.790 | 3.642 | 여러 트리 평균. 제한한 설정에서 CV가 더 높음 |

**Ridge에서 Elastic Net으로 변경한 이유:** DAY1의 Ridge는 작은 표본과 피처 중복을 고려한 출발 전략이었습니다. 최초 개발에서는 ΔQ 1개·원 Target·단순성 우선 규칙으로 Ridge를 골랐습니다. 이후 논문의 방전 피처 확장과 로그 수명 예측을 반영하고 평균 CV 최소 규칙으로 비교해 Elastic Net을 선정했습니다.

| 항목 | 초기 Ridge | 최종 Elastic Net |
|---|---|---|
| 입력 | ΔQ 로그분산 1개 | 초기 방전 관련 5개 |
| Target | 원래 수명 | log10 수명 |
| 선정 규칙 | 최저 CV+1%p 이내 단순 모델 우선 | 평균 CV MAPE 최소 |
| CV MAPE | 8.718% | 4.775% |
| Hold-out MAPE | 9.907% | 5.695% |
| Batch 2 MAPE | 25.688% | 25.642% |
| Batch 2 RMSE | 153.23사이클 | 223.14사이클 |

피처·Target·선택 규칙이 함께 바뀌어 CV 개선 약 3.943%p를 Elastic Net 알고리즘만의 효과로 볼 수 없습니다. 같은 방전 5개·로그 Target의 Ridge와는 CV 차이가 약 0.219%p로 작으며, 통계적 우위를 입증한 것은 아닙니다. 초기 모델보다 외부 MAPE 개선은 약 0.046%p에 그쳤고 RMSE는 커졌습니다.

**앙상블을 채택하지 않은 이유:** 최상위 Voting은 Elastic Net과 Ridge의 원 단위 예측을 50:50 평균합니다. CV 4.984%, Hold-out 5.735%, Batch 2 MAPE 25.368%였습니다. Batch 2는 약 0.275%p 낮지만 CV·Hold-out은 개선하지 못해 테스트 점수로 교체하지 않았습니다. Stacking과 Bagging도 CV 개선이 없었습니다.

### 학습 및 최적화 전략

1. Batch 1을 개발 28셀·15정책과 Hold-out 8셀·5정책으로 나누고 정책 겹침이 없는지 확인합니다.
2. 개발 셀에 4-fold GroupKFold를 적용합니다. 중간값 대체와 표준화는 Pipeline 내부에서 각 학습 fold에만 적합합니다.
3. 원/로그 Target, 피처 조합, 모델 하이퍼파라미터의 유한 그리드를 비교합니다. 최초 161개 후보·644회 CV 학습, 추가 탐색 200개 설정 중 199개 평가 완료입니다. 두 탐색은 중복 후보가 있어 독립 361개로 합산하지 않습니다.
4. 평균 CV MAPE 최소, 동률이면 작은 표준편차로 선택합니다. 로그 모델도 역변환한 사이클 수로 평가합니다.
5. 개발용 모델로 Hold-out을 확인하고 선택 설정을 Batch 1 전체 36셀로 재학습해 Batch 2를 평가합니다.
6. 모델 저장·복원 예측 일치, 정책 분리, 입력 해시를 확인하고 셀별 오류를 분석합니다.

초기 Elastic Net 그리드는 alpha=[0.001,0.01,0.1], l1_ratio=[0.1,0.5,0.9], Ridge는 alpha=[0.1,1,10]이었습니다. 추가 탐색에서는 Elastic Net alpha를 0.0001~0.01, Ridge를 0.01~100으로 확장했습니다. 구체적인 후보 설정은 02·03 코드에 있습니다.

동일 배터리의 사이클을 서로 독립적인 셀처럼 나눠 학습하지 않습니다. 설정은 개발용 CV로 선택했지만 이전 Hold-out·Batch 2를 확인한 재분석 이력이 있습니다. 완전히 새로운 독립 테스트라는 주장이나 전체 후보 선택까지 포함한 nested CV를 수행했다는 주장은 하지 않습니다.

## 성능 결과

| 구분 | MAPE (%) | 비고 |
|---|---:|---|
| Train (Batch 1 CV) | 4.775 | 개발용 4-fold 그룹 CV 평균 |
| Valid (Batch 1 Hold-out) | 5.695 | 셀·충전 정책 그룹 Hold-out |
| Test (Batch 2) | 25.642 | Batch 1 전체 재학습 후 평가 |
| Gap (Train-Valid) | +0.920 | Valid−Train; 내부 오차 증가 |
| Gap (Valid-Test) | +19.948 | Test−Valid; 외부 일반화 저하 |
| Gap (Target-Test) | +16.542 | Test−9.1; 과제 목표 미달 |

성능은 %, Gap은 **%p**입니다. 양수는 오차 증가를 뜻합니다. Train은 CV 검증 오차의 평균이며 학습 데이터 적합 오차가 아닙니다. Batch 2 MAE는 **155.61사이클**, RMSE는 **223.14사이클**입니다.

**Gap 해석:** 내부 차이 +0.920%p만으로 과적합을 확정하기 어렵습니다. 검증 셀이 8개이고 fold와 구성도 다릅니다. 외부 차이 +19.948%p는 Batch 간 성능 저하를 보여주며 수명·입력 분포 차이와 과대예측이 관찰됐습니다. 특정 원인의 기여도를 분리한 실험은 아닙니다. 목표 차이 +16.542%p로 9.1%를 달성하지 못했습니다.

논문 Table 1의 기본 Primary test와도 비교했습니다.

| 논문 모델 | Primary MAPE | Primary RMSE | 우리 MAPE−논문 |
|---|---:|---:|---:|
| Variance | 14.7% | 138사이클 | +10.942%p |
| Discharge | 13.0% | 91사이클 | +12.642%p |
| Full | 14.1% | 118사이클 | +11.542%p |

초록·과제 목표의 9.1%는 위 표의 특정 모델 테스트값과 구분합니다. 논문 Train 41셀·Primary test 43셀과 현재 36·39셀, 데이터 날짜·분할·피처 구현이 달라 참고 비교이며 완전 재현이 아닙니다. 논문의 이상 테스트 셀 1개 제외 결과는 Variance/Discharge/Full 13.2/10.1/7.5%입니다. 이번에는 확정 수명 39셀을 모두 평가했습니다.

## 오류 분석

- 가장 큰 상대오차는 **cell 44: 실제 841 → 예측 1,604.33사이클, APE 90.76%**, 다음은 **cell 9: 실제 791 → 예측 1,440.14, APE 82.07%**입니다.
- 두 셀 모두 실제 수명은 학습 범위 안에 있지만 일부 ΔQ·초기 용량 피처가 학습 범위를 벗어납니다. 정책명에는 `newstructure`가 있습니다. 이것만으로 셀 구조가 오류의 원인이라고 단정하지 않습니다.
- Batch 2의 39셀 중 34셀을 과대예측했고 평균 편향은 **+144.25사이클**, 최대 과대예측은 **+763.33사이클**입니다. 초기 Ridge보다 최대 과대예측과 RMSE가 커졌습니다.
- 2사이클 QD 평균은 Batch 1 **1.07794 Ah**, Batch 2 **1.09351 Ah**입니다. 입력 관계 이동, 계수 외삽, 측정 기준·곡선 정렬·셀 구조 차이를 원인 가설로 검토합니다.
- 개선 방향은 측정·정렬 기준 확인, 새 외부 데이터 확보, 피처별 추가 효과와 예측 불확실성 검증입니다. 큰 오류 셀을 결과에 맞춰 제거하거나 Batch 2 정답·평균에 맞춰 사후 보정하지 않습니다.

## ESS 도메인 해석

### 실제 BESS에서 활용할 의사결정

추가 검증 후 초기 신호로 수명이 짧을 가능성이 높은 셀을 점검 후보로 올리고 교체 계획의 참고 정보로 활용할 수 있는지 검토합니다. 실제 용량·저항·온도 이력과 함께 판단하고, 학습 입력 범위를 벗어나는 셀은 별도 검토 대상으로 구분해야 합니다.

수명 과대예측은 예측을 그대로 신뢰할 때 교체 지연으로, 과소예측은 불필요하게 이른 점검·교체로 연결될 수 있습니다. 그래서 MAPE뿐 아니라 사이클 단위 MAE·RMSE, 과대예측 비율·편향·최대 오차도 함께 봅니다. 최종 모델의 과대예측 비율 87.18%는 실패 확률이나 안전 인증 지표가 아닙니다.

### 한계와 실 배포 전 추가 검증

| 구분 | 현재 한계 | 추가로 필요한 것 |
|---|---|---|
| 데이터 | 작은 표본, 미확정 라벨, 제한된 충전 정책·수명 범위 | 신규 셀·운전 조건 데이터와 충분한 수명 관측 |
| 모델·평가 | 큰 과대예측, 중복 피처, 많은 후보 선택, 이미 확인한 검증·테스트 | 전체 탐색의 nested 그룹 CV 또는 새 독립 데이터, 오차 방향·불확실성 평가 |
| 실제 적용 | 실험실 셀과 ESS 팩의 온도·부하·휴지·불균형·달력 열화 차이 | 실제 운전 조건과 목표 EOL 정의에서 별도 검증 |
| 비즈니스 | 교체비용·중단시간·오류별 비용·허용 기준 부재 | 운영 담당자와 점검 기준 설정, 실제 비용·운영 성과 평가 |

이 모델은 초기 신호로 **총 Cycle Life**를 예측하며 매 시점의 잔여수명, 교체 날짜, 화재·고장 확률을 직접 예측하지 않습니다. 현재 결과만으로 자동 충전 제어나 교체 시점을 결정할 수 없습니다. 비용 절감액도 계산하지 않았습니다. 현재 모델은 정한 CV 기준의 개발 결과이며 운영 적합성이 확인된 모델은 아닙니다.
