# ESS 배터리 수명 예측

배터리의 초기 100사이클 충·방전 신호를 이용해 최종 수명(`cycle_life`)을 예측합니다. **Batch 1에서 모델을 학습하고 내부 검증으로 설정을 선택한 뒤, Batch 2에서 예측 성능을 최종 검토합니다.** Batch별 EDA에서 찾은 신호를 피처와 모델 설계에 반영합니다. 향후 ESS 점검 우선순위와 교체 계획에 활용할 가능성을 검토하는 것이 목적입니다.

## 프로젝트 개요

- 데이터셋: MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터: **Batch 1 (2017-05-12), 확정 라벨 36셀**
- 최종 검토 데이터: **Batch 2 (2018-02-20), 확정 라벨 39셀**
- 태스크: **Regression — Cycle Life 예측**
- 입력: 초기 100사이클 이내에서 추출한 피처
- 주 평가 지표: MAPE(%), 보조 지표: MAE·RMSE(사이클)
- 최신 개선 모델: **Ridge(alpha=1), 상대 용량·중심화 ΔQ 피처**, Batch 2 MAPE **20.176%**

## EDA

### Cycle Life 분포

| Batch | 확정 라벨 셀 수 | 평균 | 중앙값 | 최소·최대 | 단수명 <500 | 장수명 >1,000 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Batch1 | 36 | 788.4 | 772.5 | 534부터 1,074까지 | 0.0% | 13.9% |
| Batch2 | 39 | 565.7 | 472.0 | 392부터 1,186까지 | 71.8% | 7.7% |
| Batch3 | 44 | 1,059.7 | 1,005.5 | 541부터 1,935까지 | 0.0% | 52.3% |

수명 단위는 사이클이며 비율의 분모는 확정 수명 라벨이 있는 셀입니다. 전체 셀 B1/B2/B3 46/47/46개 중 라벨이 없는 10/8/2개는 지도학습과 수명 통계에서 제외했습니다. 수명을 평균이나 관측 길이로 대체하지 않았습니다.

Batch 1은 중간 수명대 중심이고, Batch 2는 단수명에 몰린 오른쪽 꼬리 분포, Batch 3은 장수명 중심의 오른쪽 꼬리 분포입니다. 확정 라벨 기준 IQR 이상치 후보는 B1/B2/B3에서 0/9/3개이며 모두 상단 후보입니다. 가장 짧은 셀은 각각 cell20(534), cell19(392), cell28(541사이클)로, 짧다는 이유만으로 오류로 제외하지 않았고 원인은 확정하지 않았습니다.

**핵심 발견:** Batch 1에 없는 500사이클 미만 셀이 Batch 2의 71.8%를 차지해 단수명 영역의 일반화가 주요 과제입니다.

### 열화 곡선 분석

사이클별 방전용량(QD)을 그려 장·단수명 셀의 용량 유지와 감소 시점을 비교했습니다. 단수명 셀은 더 이른 사이클에 용량 감소가 나타나며, 셀별 열화 속도는 전 구간에서 일정하지 않습니다. 중기 대비 말기 감소 속도 비율 중앙값은 B1/B2/B3에서 약 11.9/12.0/9.4배였습니다.

이동평균과 곡선 변화량으로 찾은 Knee 후보의 중앙값은 확정 라벨 셀 기준 B1/B2/B3에서 **767/468/986.5사이클**입니다. 잡음·끝단·탐색 방법에 민감해 실제 급락 시작점으로 확정하지 않았으며, 전체 곡선의 Knee와 중·말기 기울기는 미래 정보여서 예측 입력에서 제외합니다.

**핵심 발견:** 셀별 열화는 말기에 가속되는 양상이 있어 초기의 일정한 감소율만으로 전체 수명을 설명하기 어렵습니다.

1.2 Ah를 넘는 용량 돌출 기록은 주변 기록과 불연속성을 확인한 뒤 가공 단계에서 제외했습니다. 원본과 셀 전체를 삭제하지 않았으며, 제외 이력은 재처리 결과에 남깁니다.

### ΔQ(V) 곡선 분석

100사이클과 10사이클의 방전 곡선 차이 `ΔQ(V)=Q100(V)−Q10(V)`를 비교했습니다. 대표 단수명 셀에서 더 깊은 음의 변화가 관찰됐고, 곡선의 분산·최솟값 등을 피처로 요약했습니다.

ΔQ 로그분산과 수명의 상관은 B1/B2/B3에서 **−0.827/−0.902/−0.702**입니다. Batch 2에서는 단수명(<500)·장수명(>1,000) 대표 곡선을 비교할 수 있지만, Batch 1·3에는 <500 셀이 없어 상대적으로 짧은 셀과 긴 셀의 비교입니다. 대표 곡선만으로 전체 셀의 구분을 확정하지 않습니다.

**핵심 발견:** ΔQ 로그분산은 세 Batch에서 수명과 일관된 음의 상관을 보여 초기 수명 예측의 핵심 피처로 선택했습니다.

### 충전 속도(C-rate)와 수명의 관계

확정 라벨 기준으로 충전 프로토콜별 평균 수명을 비교했습니다.

| Batch | 최저 평균 수명 정책 | 평균 / 셀 수 | 최고 평균 수명 정책 | 평균 / 셀 수 |
| --- | --- | ---: | --- | ---: |
| Batch1 | `5.4C(80%)-5.4C` | 546.5 / 2 | `4.4C(80%)-4.4C` | 1,074.0 / 1 |
| Batch2 | `3.6C(9%)-5C` | 394.5 / 2 | `5.6C(26%)-4.5C-newstructure` | 991.3 / 3 |
| Batch3 | `3.7C(31%)-5.9C-newstructure` | 660.0 / 3 | `4.8C(80%)-4.8C-newstructure` | 1,564.2 / 6 |

평균 수명의 단위는 사이클입니다. 정책별 표본 수가 작으므로 위 최고·최저 평균은 정책의 우열이나 인과효과를 입증하지 않습니다.

실측 전류 Iqw와 수명의 상관은 B1/B2/B3에서 **−0.845/−0.301/−0.650**으로 Batch 2에서 약했습니다. 전류 패턴과 열화 속도의 관계는 수명 상관만으로 입증되지 않으며, 셀 구조·전환 SOC·온도 등의 영향을 분리하지 못했습니다. 전류·충전시간을 후보 피처로 비교하고 충전 정책 그룹을 분리해 검증했습니다.

**핵심 발견:** 충전 조건과 수명의 관계가 Batch마다 달라 C-rate가 높으면 반드시 수명이 짧다고 단정할 수 없습니다.

### 상관관계와 다중공선성

초기 숫자 피처 사이에 절대 상관 0.90 이상인 쌍은 B1/B2/B3에서 **33/30/36개**였습니다(셀 ID·정답·제공 라벨·관측 길이·Knee·곡선 인덱스 제외). 초기 SOH 기울기의 수명 상관은 **+0.507/−0.442/+0.333**으로 Batch에 따라 부호가 달랐습니다.

규제 회귀인 Ridge·Elastic Net을 우선 비교하고 관계가 불안정한 변수는 제외·추가 실험으로 검토했습니다. 상관계수는 예측 성능이나 원인 효과를 뜻하지 않습니다.

**핵심 발견:** 피처 중복과 Batch별 상관 부호 변화가 있어, 일관된 ΔQ 신호를 중심으로 규제 회귀와 피처 제거 실험을 설계했습니다.

## Modeling

### 피처 엔지니어링 전략

기존 절대 초기 용량 피처는 Batch별 측정 기준 차이에 민감할 수 있어 상대 변화량으로 바꾸고, ΔQ 곡선의 상수 수준에 덜 민감한 중심화 피처를 비교했습니다.

| 최신 모델 입력 | 계산·의미 | 선정 이유 |
| --- | --- | --- |
| `delta_q_log_variance` | ΔQ(V)=Q100(V)−Q10(V)의 분산 로그 | 세 Batch에서 유지되는 음의 수명 상관 |
| `dq_log_centered_min` | log10(abs(ΔQ 최솟값−ΔQ 평균)) | 곡선 전체의 상수 수준보다 평균 대비 음의 변화 크기 요약 |
| `qd_rel_gain` | (2부터 100까지사이클 최대 QD−2사이클 QD) / 2사이클 QD | 초기 용량 수준을 나눠 상대 증가량 표현 |
| `qd_rel_slope` | 2부터 100까지사이클 QD 기울기 / 2사이클 QD | 초기 용량 수준을 나눠 상대 변화 속도 표현 |

최신 입력은 모두 초기 100사이클 이내에서 계산합니다. 셀 ID·정답·관측 길이·전체 곡선 Knee·중말기 정보는 학습 피처에서 제외합니다. 충전 정책은 그룹 분리에 사용합니다. ΔQ 중심화는 상수 수준에 대한 민감도를 줄이는 수학적 처리이며, 실제 배치 차이가 모두 상수 이동이라는 뜻은 아닙니다.

### 모델 선택 및 변경 과정

**DAY1의 Ridge는 EDA 기반의 우선 후보였으며, 현재 최종 모델도 Ridge입니다.** 중간에 Elastic Net을 선택했다가, 입력 피처와 검증 기준을 보완하면서 다시 Ridge를 선정했습니다.

| 단계 | 선택과 변경 이유 | 확인한 결과 |
| --- | --- | --- |
| DAY1: Ridge 우선 선정 | 셀 수가 적고 피처 간 상관이 높아, 계수 크기를 줄이는 규제 회귀를 출발점으로 선택 | 초기 ΔQ 단독 Ridge의 CV MAPE 8.718%, Batch 2 25.688% |
| DAY2: Elastic Net 선정 | 논문의 로그 수명·피처 확장 아이디어를 반영하고 161개 후보를 비교. L1·L2 규제를 함께 쓰는 Elastic Net 조합이 일반 CV에서 가장 낮은 오차를 보여 선정 | CV 4.775%, Hold-out 5.695%, Batch 2 25.642%. 내부 성능 개선에 비해 외부 MAPE 개선은 작았음 |
| 추가 개선: Ridge 재선정 | 초기 용량의 절대값 의존을 줄이는 상대 피처와 중심화 ΔQ를 비교. 용량 기준값 변화에 대한 가상 조건 CV를 선정 기준으로 추가 | 최신 Ridge의 일반 CV 6.214%, 가상 조건 CV 6.249%, Batch 2 20.176% |

**변경의 근거는 논문과 같은 모델을 쓰는 것 자체가 아니라, 각 단계에서 정한 검증 기준입니다.** 이전 Elastic Net의 가상 조건 CV는 14.161%로 최신 Ridge보다 높았습니다. 피처·Target·검증 기준도 함께 바뀌었으므로 개선을 Ridge 알고리즘만의 효과로 설명하지 않습니다.

최신 모델은 **Ridge(alpha=1), log10(cycle_life)**이며 예측을 사이클 단위로 역변환합니다. 가상 조건 검증은 QD 기준값에 0, ±0.015, ±0.030 Ah를 적용한 민감도 실험으로, 실제 센서 오차나 운영 조건이 확인된 것은 아닙니다. 상대 용량만 사용한 Ridge는 Batch 2 MAPE 19.390%로 더 낮았지만, 최종 선정 기준인 가상 조건 CV는 6.602%로 더 높아 중심화 Ridge를 유지했습니다.

### 학습 및 최적화 전략

1. **Batch 1 분할:** 확정 라벨 36셀 중 개발 28셀, Hold-out 8셀. 충전 정책 그룹을 분리하고 개발 세트에서 4-fold GroupKFold를 수행합니다.
2. **전처리:** 결측 중앙값 대체·표준화는 학습 fold에서만 적합합니다. 초기 100사이클 피처만 사용하며 전체 곡선의 미래 정보는 제외합니다.
3. **후보 비교:** 02의 161개 후보와 03의 앙상블을 비교한 뒤, 04에서 일반 CV 637개 설정·오프셋 증강 36개 설정·보완 후보 180개 설정을 단계적으로 검토했습니다. 일반 CV와 가상 조건 CV는 구분합니다.
4. **최종 학습·평가:** 선택한 설정으로 Batch 1 전체 36셀을 학습하고 Batch 2의 39셀을 평가합니다. Batch 2 정답은 계수 학습에 사용하지 않았고 Batch 3은 제외합니다.

## 성능 결과

최신 04 개선 모델 기준입니다. 일반 조건 CV를 과제의 Train 항목에 기재하고, 모델 선정에 사용한 가상 조건 CV 6.249%는 별도 지표로 구분합니다.

| 구분 | MAPE (%) | 비고 |
| --- | ---: | --- |
| Train (Batch 1 CV) | 6.214 | 일반 조건 그룹 CV; 모델 선택은 별도 용량 기준 검증 |
| Valid (Batch 1 Hold-out) | 4.611 | 고정 정책 그룹 Hold-out |
| Test (Batch 2) | 20.176 | Batch 1 전체 학습 모델의 Batch 2 성능 검토 |
| Gap (Train-Valid) | -1.603 | Valid - CV (%p) |
| Gap (Valid-Test) | +15.564 | Test - Valid (%p) |
| Gap (Target-Test) | +11.076 | Test - 9.1 (%p) |

성능은 %, Gap은 %p입니다. Train은 학습 적합 오차가 아니라 개발용 fold 검증 오차 평균입니다. 최신 Batch2 MAE는 **122.30사이클**, RMSE는 **173.91사이클**입니다.

기존 Elastic Net 대비 MAPE **5.467%p 감소**(상대 감소 약 21.3%), RMSE **49.23사이클 감소**입니다. 목표 9.1%에는 **11.076%p 미달**했습니다. 성능을 맞추기 위해 라벨이나 테스트 셀을 바꾸지 않았습니다.

**Gap 해석:** Hold-out이 일반 CV보다 1.603%p 낮아 이 결과만으로 과적합을 주장하지 않습니다. 검증은 8셀이고 구성 차이가 있습니다. 외부 차이 +15.564%p는 여전히 배치 일반화 문제를 보여줍니다. 가상 조건 검증 개선이 실제 외부 오차의 모든 원인을 해결했다는 뜻은 아닙니다.

| 논문 모델 | Primary MAPE | Primary RMSE | 최신 MAPE−논문 |
| --- | ---: | ---: | ---: |
| Variance | 14.7% | 138사이클 | +5.476%p |
| Discharge | 13.0% | 91사이클 | +7.176%p |
| Full | 14.1% | 118사이클 | +6.076%p |

과제·초록 목표 9.1%와 논문 Table 1의 모델별 기본 Primary test를 구분합니다. 논문 Train 41셀·Primary test 43셀과 현재 36·39셀, 날짜·분할·피처 구현이 달라 참고 비교이며 완전 재현이 아닙니다. 논문의 이상 테스트 셀 1개 제외 값 13.2/10.1/7.5%를 이번 39셀 평가에 적용하지 않았습니다.

## 오류 분석

- **큰 오류:** cell44는 실제 841 → 예측 1,472.28사이클(APE 75.06%), cell9는 791 → 1,213.15사이클(53.37%)입니다. 두 셀은 학습 수명 범위 안에 있고 정책명에 `newstructure`가 있지만, 구조 차이만으로 원인을 확정하지 않습니다.
- **오차 방향:** 과대예측 30/39셀(76.92%), 평균 편향 +84.97사이클, 최대 과대예측 +631.28사이클입니다. APE 중앙값은 16.64%, 90백분위수는 40.87%로 큰 오차가 남아 있습니다.
- **원인 가설:** Batch 1에 없는 단수명 구간, 초기 용량 기준·셀 구조·전압 곡선 정렬 차이가 영향을 줄 수 있습니다. 원인별 기여도는 분리 검증하지 않았습니다.
- **개선 방향:** 사이클 대응·전압 정렬·EOL 정의를 재확인하고, 단수명과 다양한 정책의 새 학습 데이터를 확보합니다. 전체 후보 선택을 포함한 nested 그룹 CV 또는 새 독립 테스트와 예측 불확실성 검증이 필요합니다.

## ESS 도메인 해석

### 비즈니스 목적에 맞춘 평가 점검

목적은 초기 100사이클의 신호로 총 수명을 예측해 **점검 우선순위와 교체 계획의 참고 정보를 제공하는 것**입니다. 예측값은 실제 용량·저항·온도 상태와 함께 검토해야 합니다.

| 분석 결과·평가 | ESS 운영 의사결정과의 연결점 | 도움이 될 수 있는 부분 |
|---|---|---|
| 초기 ΔQ와 상대 용량 변화에서 수명 관련 신호 확인 | 예측 수명이 짧은 셀을 우선 점검 후보로 검토 | 용량 감소가 뚜렷해지기 전부터 상태 확인 대상을 좁히는 데 참고. 점검 순위의 정확도는 별도 검증 필요 |
| MAPE 20.176%, MAE 122.30사이클, RMSE 173.91사이클 | 예측 수명과 함께 오차 규모를 보고 교체 계획 검토 | 예측값을 확정 수명으로 받아들이지 않고 추가 상태 진단이 필요한지 판단하는 근거. 논문 목표 9.1%는 운영 허용 기준이 아님 |
| 과대예측 30/39셀, 평균 편향 +84.97사이클 | 실제보다 오래 사용할 수 있다고 판단해 교체가 늦어질 가능성 점검 | 예측만으로 사용 기간을 연장하지 않고 용량·저항·온도 확인과 담당자 검토를 병행할 근거. 과대예측 비율은 고장 확률이 아님 |
| Batch 간 수명 분포·예측 성능 차이 | 새로운 셀·충전 조건에 모델을 적용하기 전 별도 검증 | 검증된 조건과 다른 입력을 구분하고 적용 범위를 정하는 데 참고 |

**평가 지표는 점검·교체 판단에 필요한 오차 크기와 방향을 확인하도록 구성했습니다.** 위 연결점은 활용 가능성에 대한 해석이며, 실제 점검 우선순위의 유용성과 운영 판단 개선을 입증한 결과는 아닙니다. 현재 결과만으로 자동 교체·충전 제어를 결정하기 어렵습니다.
